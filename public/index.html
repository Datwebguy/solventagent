Make your agent pay for its own thinking

Run the Solvent proxy next to your agent

git clone https://github.com/Datwebguy/solventagent solvent && cd solvent && npm install
npm run cli usepod:register     # compute reserve on UsePod
npm run cli usepod:deposit 2 --yes
npx tsx src/server.ts

Point any OpenAI or Anthropic client at it

OPENAI_BASE_URL=http://127.0.0.1:8787/v1      # model: "auto"
ANTHROPIC_BASE_URL=http://127.0.0.1:8787

Model "auto" picks the tier your runway can afford. Empty reserve → HTTP 402, the agent sleeps instead of overspending.

Give Hermes (claw-agent) its books

# ~/.hermes/config.yaml
mcp_servers:
  solvent:
    command: npx
    args: ["tsx", "/path/to/solvent/src/mcp.ts"]

Tools: solvent_books, solvent_ledger, solvent_policy, solvent_plan_cycle, solvent_run_cycle, solvent_pay_with_ansem, solvent_audit_agent.

Route creator fees to the treasury

Set your ClawPump agent's payout wallet to the treasury. The hourly cycle detects ClawPump fee payouts, tops up the compute reserve, buys the $ANSEM reserve, runs buybacks, and anchors the ledger.

Every number here is either on-chain or in a hash-chained ledger whose fingerprints are written to Solana. Prompts are never stored or published. Built for the AnsemHack Clawrena on ClawPump × UsePod.
