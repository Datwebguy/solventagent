No-code setup: 3 steps

About 5 minutes. No sign-up, no code, nothing to install.

  1. Pick one wallet

    Use the wallet that receives your agent's token earnings.

    • On ClawPump, that's your agent's payout wallet.
    • Copy its address (it looks like 8kZB…YS).

  2. Pay for its AI from it

    Buy your agent's AI on UsePod and top up from that same wallet.

    • That's how the chain shows what your agent spends.
    • Paying from another wallet still works, but your page will say no AI costs seen.

  3. Open and share your page

    Paste the wallet below. Your page updates by itself from then on.

    • Pin the link in your X bio or announcement.
    • Share it with holders and the judges.

The page is read straight from Solana each time someone opens it. Nothing is saved and nothing is signed.

For developers: run the full engine

The no-code page shows your books. The engine goes further: your agent's earnings pay for its AI automatically, under a budget it can't break.

What the engine adds

A CFO inside your agent

An OpenAI/Anthropic-compatible proxy pays UsePod for every AI call. It picks cheaper models as money runs low and pauses instead of overspending. Earnings are split by rules you publish on Solana, with hard caps per payment and per day. Every record is chained and anchored on-chain.

What you need

About 20 minutes

Node.js 24, a Solana wallet with a little SOL for fees, and your agent pointed at a new model address. It works with any client that speaks the OpenAI or Anthropic API, and with Hermes / claw-agent over MCP.

  1. Get the code

    git clone https://github.com/Datwebguy/solventagent
cd solventagent
npm install
cp .env.example .env

  2. Add your treasury wallet

    Put the wallet's private key in .env as SOLVENT_TREASURY_SECRET. Use a dedicated wallet holding only what the agent needs.

    npm run cli wallet     # shows the address and balances, read-only

  3. Open the AI budget on UsePod and fund it

    npm run cli usepod:register          # saves the UsePod token to .env
npm run cli usepod:deposit 2 --yes   # $2 of AI to start

  4. Publish your budget rules

    Default split: 50% AI budget, 20% $ANSEM savings, 20% operating cash, 10% buyback. Edit solvent.policy.json before committing if you want different numbers.

    npm run cli policy:init
npm run cli policy:commit --yes      # puts the rules' fingerprint on Solana

  5. Point your agent at Solvent

    npx tsx src/server.ts

# then, in your agent (model "auto"):
OPENAI_BASE_URL=http://127.0.0.1:8787/v1
ANTHROPIC_BASE_URL=http://127.0.0.1:8787

    Using Hermes or claw-agent? Add Solvent as an MCP server and give the agent skills/solvent/SKILL.md:

    # ~/.hermes/config.yaml
mcp_servers:
  solvent:
    command: npx
    args: ["tsx", "/path/to/solventagent/src/mcp.ts"]

  6. Check it

    npm run cli think "What should an agent do when its runway drops below 3 days?"
npm run cli status
npm run cli cycle            # dry run: income found and the plan, nothing sent

    Set SOLVENT_AUTOPILOT=1 when you want the hourly cycle to move money by itself, and SOLVENT_PUBLISH=1 to publish public books.

Never commit .env or share your private key. The proxy only listens on your own machine unless you set SOLVENT_PROXY_KEY. Full details are in the README.

Questions

Does Solvent hold my money or keys?

No. The no-code page only reads public blockchain records. With the engine, your key stays in your own .env on your own machine; Solvent's servers never see it.

What does it cost?

Nothing. The page is free and the engine is open source. With the engine you pay UsePod for your agent's AI, from your agent's own earnings.

My page says "no AI costs seen". Why?

Your agent is paying for its AI from a different wallet, or not through UsePod. Top up UsePod from the wallet that receives your token earnings and the costs will show up.

Several of our agents share one wallet.

That's fine. The page and the ranking show that wallet's combined earnings and costs.

How often does my page update?

Every time someone opens it: it reads the chain fresh. The ranking is rebuilt twice a day.

Where do I get help?

Open an issue on GitHub, or reply to the Solvent account on X.
